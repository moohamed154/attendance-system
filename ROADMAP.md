# Product Roadmap

## Version 1.1 (Current)
- [x] Refactor architecture into domain-driven folders.
- [x] Generate comprehensive documentation (`docs/`, `AI_GUIDE.md`, `ARCHITECTURE.md`).
- [x] Ensure 100% backward compatibility and system stability.
- [x] Centralize shared constants.

## Version 1.2
- [ ] Implement robust Types mapping to Prisma models (`types/`).
- [ ] Fully extract inline validations into `lib/validators/`.
- [ ] Implement Custom Hooks (`hooks/`) to abstract React logic from large components.
- [ ] Optimize large lists with virtualization (e.g., Attendance History).

## Version 2.0
- [ ] Add Multi-Center Support (tenant isolation).
- [ ] Introduce real-time attendance syncing via WebSockets.
- [ ] Expand student portal with push notifications and offline PWA support.
- [ ] Add more comprehensive analytics dashboards for Center Managers.

## Version 3.0
- [ ] Migrate database to PostgreSQL for massive scalability.
- [ ] Mobile Application wrapper for Student Portal (React Native / Capacitor).
- [ ] Advanced Machine Learning insights on attendance drop-off rates.
